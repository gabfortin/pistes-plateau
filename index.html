À propos de cette carte

Cette carte recense les aménagements cyclables du Plateau-Mont-Royal, classés par type (de la simple chaussée désignée jusqu'aux pistes unidirectionnelles protégées), ainsi que les intersections dangereuses pour les cyclistes.

Données : relevé maison, publié sur GitHub (pistes.md et intersections.md). Fond de carte © OpenStreetMap.

Carte réalisée par Gabriel Fortin, conseiller d'arrondissement au Plateau-Mont-Royal.
